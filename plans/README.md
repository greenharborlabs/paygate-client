# Historical plans

Files in this directory record how the Python client, payer backends, native
qualification, and Rust migration were designed. They are retained for design
history and audit context.

They are not current installation, backend-support, or release instructions.
For the shipped Rust CLI, use the [project README](../README.md) and
[documentation index](../docs/README.md). When a plan conflicts with current
Rust source or current documentation, the source and current documentation win.
